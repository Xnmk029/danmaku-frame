# DeepSeek 网页端设计规范（截图提取）

> 来源：用户提供的 2048 × 1026 深色模式截图。  
> 本文是基于截图的视觉测量与设计推断，不代表 DeepSeek 官方设计系统或源码。坐标、字体与颜色可能受截图缩放、抗锯齿和显示色彩管理影响。

## 1. 设计概览

界面采用典型的 AI 对话产品布局：固定左侧导航栏 + 大面积主工作区。整体强调低干扰、强层级和单任务聚焦。

- 深色中性背景占据绝大部分面积，降低长时间使用的视觉疲劳。
- 品牌蓝只用于 Logo、当前状态、主要操作和功能标签。
- 主要内容集中在页面中部偏上位置，四周保留大量负空间。
- 组件以圆角胶囊和大圆角面板为主，减少工具感，提升亲和力。
- 边框主要通过极低对比度灰线表达，不使用明显投影。
- 导航信息密度高，但通过日期分组、行距和不同灰阶维持可扫描性。

### 2.2 主内容对齐逻辑

- 主工作区不是以整个视口居中，而是在扣除侧栏后居中。
- 内容主轴约在 `x = 1208px`。
- 标题、模式切换器与输入面板共享同一水平中心。
- 输入面板比模式切换器宽约 2.1 倍，形成“选择模式 → 输入任务”的视觉漏斗。
- 主内容顶部留白较大，标题基线位于视口高度约 30% 处。

### 3.2 色彩使用原则

- 背景采用相近的黑灰色，不使用纯黑 `#000000`。
- 前景表面通过约 5%–12% 的亮度差建立层次。
- 白色文字避免使用纯白，主文字建议 `#F2F2F3`。
- 品牌蓝只承担“可交互、已选中、品牌识别”三种语义。
- 激活状态同时使用蓝色文字、蓝色边框和蓝灰底色，不能只依赖颜色变化。
- 整体不使用阴影；层级依赖背景明度、边框和间距。

## 4. 字体与排版

### 4.1 字体推断

截图无法确认实际 Web Font。视觉上接近系统无衬线字体组合，建议使用：

```css
font-family:
  Inter,
  -apple-system,
  BlinkMacSystemFont,
  "Segoe UI",
  "PingFang SC",
  "Microsoft YaHei",
  "Noto Sans CJK SC",
  sans-serif;
```

- 中文字形偏现代黑体，笔画均匀，字面较大。
- 英文字形接近 Inter / Segoe UI 一类的中性 UI 字体。
- Logo 字标为独立品牌字形，不应直接用正文系统字体替代。

### 4.2 字体层级

| 样式 | 近似规格 | 用途 |
| --- | --- | --- |
| 主标题 | `32px / 1.25`，`700` | “使用快速模式开始对话” |
| 模式标签 | `20px / 1.4`，`500–600` | 快速模式、专家模式、识图模式 |
| 输入占位符 | `24px / 1.4`，`400` | “给 DeepSeek 发送消息” |
| 侧栏正文 | `20px / 1.45`，`400–500` | 历史会话标题 |
| 侧栏分组 | `18px / 1.4`，`400` | 今天、昨天、7 天内 |
| 按钮文字 | `20px / 1`，`500` | 开启新对话 |
| 功能胶囊 | `18px / 1`，`500` | 深度思考、智能搜索 |
| 用户名 | `18px / 1.4`，`400–500` | 侧栏底部用户信息 |

### 4.3 排版规则

- 主标题使用粗体，其他位置最多使用中等字重，避免界面过重。
- 侧栏历史记录单行展示，超长文本应省略：

```css
white-space: nowrap;
overflow: hidden;
text-overflow: ellipsis;
```

- 日期分组与首条记录之间约 `16–20px`。
- 历史记录行高约 `56px`，保证可点击区域充足。
- 中文和英文混排保持默认字距；品牌 Logo 除外。

## 5. 间距、尺寸与圆角

### 5.1 建议间距系统

采用 4px 基础网格：

```text
4 / 8 / 12 / 16 / 20 / 24 / 28 / 32 / 40 / 48 / 64
```

常用映射：

- 图标与文字：`8–12px`
- 胶囊内部水平间距：`16–20px`
- 侧栏左右内边距：`20–28px`
- 历史记录垂直节奏：`20–32px`
- 标题到模式切换器：约 `36px`
- 模式切换器到输入面板：约 `50px`
- 输入面板内边距：`20–24px`

### 5.2 圆角

| 组件 | 建议圆角 |
| --- | --- |
| 新对话按钮 | `28–30px`，完整胶囊 |
| 模式切换器外框 | `28–30px` |
| 激活模式项 | `28–30px` |
| 输入面板 | `34–36px` |
| 功能标签 | `22–24px` |
| 发送按钮 | `50%`，圆形 |
| 头像 | `50%` |

## 6. 组件规范

### 6.1 左侧导航栏

- 固定宽度约 `365px`，高度 `100vh`。
- 背景比主画布略亮：`#1B1B1C`。
- 右侧使用 1px 弱分隔线：`#29292B`。
- 内部纵向结构：
  1. 品牌与工具栏；
  2. 新对话主按钮；
  3. 可滚动历史记录；
  4. 固定底部用户区域。
- 历史区允许独立滚动，顶部与底部区域不滚动。

### 6.2 顶部品牌区域

- Logo 左对齐，整体高度约 `30px`。
- 搜索和侧栏收起图标右对齐。
- 工具图标约 `22–24px`，默认色 `#ACADAE`。
- 图标按钮应提供不小于 `40 × 40px` 的点击热区，即使视觉图标更小。

### 6.3 新对话按钮

- 宽度占侧栏可用区域的大部分，左右留约 `14–18px`。
- 高度约 `57px`。
- 背景 `#43454A`，文字 `#F2F2F3`。
- 图标位于文字左侧，间距约 `10px`。
- 悬停时可提高背景亮度 4%–6%，按下时轻微降低。

### 6.4 历史会话列表

- 日期分组使用次级灰色，不使用粗体。
- 会话标题使用主文字色。
- 每个条目应具有完整行点击区，而不是只有文字可点击。
- 当前截图未显示选中条目；建议选中状态采用 `#2C2C2E` 背景和 `10–12px` 圆角。
- 禁用或低优先级记录使用 `#6F6F71`。

### 6.5 模式标题

- 由蓝色品牌图标和粗体标题组成。
- 图标视觉尺寸约 `46 × 32px`，与标题垂直居中。
- 图标和标题间距约 `14px`。
- 标题不需要副标题，保持单一视觉焦点。

### 6.6 模式切换器

- 三段式胶囊选择器，整体高度约 `58px`。
- 外层背景 `#222224`，带 1px 弱边框。
- 各项使用图标 + 标签，内部水平居中。
- 激活项：
  - 背景 `#2B3548`；
  - 边框 `#4B72D4`；
  - 图标和文字 `#5791F8`；
  - 不使用投影。
- 非激活项使用 `#F2F2F3`，悬停时背景略亮。
- 每项点击区域高度应覆盖整个切换器。

### 6.7 消息输入面板

- 尺寸约 `1094 × 174px`。
- 背景 `#2C2C2E`，1px 边框 `#3A3A3D`。
- 圆角约 `35px`。
- 文本输入区域位于上部，左右内边距约 `24px`。
- 占位符颜色 `#8D8D8F`，字号约 `24px`。
- 底部操作区：
  - 左侧：功能标签；
  - 右侧：附件按钮与发送按钮；
  - 与面板底边保持约 `18px`。

### 6.8 功能标签

- “深度思考”“智能搜索”采用独立描边胶囊。
- 高度约 `46px`，水平内边距约 `14–16px`。
- 透明或与输入面板一致的背景。
- 边框与文字使用品牌蓝。
- 图标约 `20px`，与文字间距约 `8px`。

### 6.9 附件与发送按钮

- 附件图标为裸图标按钮，视觉尺寸约 `22px`，热区至少 `40px`。
- 发送按钮为直径约 `48px` 的圆形按钮。
- 默认或不可发送状态使用低饱和蓝灰 `#495982`。
- 可发送状态建议改为品牌蓝 `#4D7DFA`。
- 箭头保持白色或浅灰，线宽约 `2px`。

### 6.10 用户区域

- 固定在侧栏底部，高约 `64px`。
- 左侧：`42–46px` 圆形头像。
- 中间：用户名，单行省略。
- 右侧：更多菜单图标。
- 与历史区之间可使用背景渐变遮罩，避免滚动内容与底栏发生视觉冲突。

## 7. 图标与视觉元素

- 图标整体采用细线、圆角端点，建议线宽 `1.8–2px`。
- 常用尺寸为 `20px`、`24px`；品牌图标除外。
- 图标默认色使用浅灰，激活图标使用品牌蓝。
- 图标与文字必须垂直居中。
- 不混用填充型和线框型图标；截图主要为线框图标。
- Logo 是最强品牌元素，其他图标应保持克制，不能抢占注意力。

## 8. 交互状态

| 状态 | 建议表现 |
| --- | --- |
| 默认 | 中性背景 + 弱边框 |
| Hover | 表面亮度提高 4%–6% |
| Active / Selected | 蓝灰背景 + 蓝色边框 + 蓝色文字 |
| Focus | 2px 品牌蓝焦点环，外扩 2px |
| Disabled | 降低文字与图标对比度，不仅降低透明度 |
| Pressed | 背景略暗，可增加 `transform: scale(0.99)` |

动画应短促克制：

```css
transition:
  background-color 160ms ease,
  border-color 160ms ease,
  color 160ms ease,
  transform 100ms ease;
```

## 9. 响应式建议

### 桌面端（≥ 1200px）

- 保持约 `365px` 固定侧栏。
- 主输入区使用 `min(1094px, calc(100vw - sidebar - 80px))`。
- 主内容保持在剩余空间水平居中。

### 中等宽度（768–1199px）

- 侧栏缩为 `280–320px`，或支持手动收起。
- 输入框左右至少保留 `32px`。
- 模式切换器允许缩短标签间距。

### 移动端（< 768px）

- 侧栏改为抽屉。
- 主内容顶部留白明显减少。
- 模式切换器可横向滚动或改为等宽三列。
- 输入面板宽度为 `calc(100vw - 24px)`，圆角降至 `24px`。
- 所有可点击区域至少 `44 × 44px`。

## 10. 无障碍与可用性

- 主文字与背景对比度目标至少达到 WCAG AA。
- 激活状态不能只靠蓝色区分，应同时提供边框和背景变化。
- 图标按钮必须有 `aria-label` 和可见焦点状态。
- 历史列表、模式切换器和输入操作应支持键盘导航。
- 输入框占位符不应承担唯一说明，必要时增加屏幕阅读器标签。
- “发送”不可用时应同时设置 `disabled` 属性。

## 11. 复刻时的优先级

1. 先准确完成侧栏宽度、主内容中心轴和输入框尺寸。
2. 再建立四级暗色表面和统一品牌蓝。
3. 统一字体、字号、圆角和 4px 间距网格。
4. 完成模式切换、输入面板与按钮状态。
5. 最后补充滚动、响应式、焦点和微交互。

## 12. 设计检查清单

- [ ] 主工作区没有使用纯黑背景。
- [ ] 侧栏宽度与内容区中心轴符合截图比例。
- [ ] Logo、新对话按钮和历史记录左边缘形成稳定对齐。
- [ ] 标题、模式切换器和输入面板水平居中。
- [ ] 品牌蓝仅用于品牌、激活和主要操作。
- [ ] 输入面板使用大圆角、弱边框，无明显阴影。
- [ ] 模式激活项同时有背景、边框和文字变化。
- [ ] 侧栏历史区可以独立滚动，用户区固定底部。
- [ ] 图标按钮拥有足够点击热区与键盘焦点。
- [ ] 移动端侧栏可收起为抽屉。

透明前后层 / 真正 L2D 接入

当前人物是参考立绘占位，没有眨眼、嘴型或追踪。接入时关闭占位立绘，在 OBS 中依次叠放：内容来源 → 后景网页 → L2D 透明来源 → 前景网页。两个网页的输出尺寸均设为 1920×1080。

后景在内容窗口处留透明洞，前景不画背景和人物。下方按钮生成带当前配置的链接；同一来源、同一浏览器环境中的输出窗口可选同步。不同浏览器与 OBS 之间不能依赖此同步，必须分别应用同一配置。

HF 使用 Static HTML 配置，index.html 已内嵌默认素材。实际部署和 VTube Studio / OBS 联调需在你的设备上完成。

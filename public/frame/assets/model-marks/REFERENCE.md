# PHASE / MARK · AI 像素标志图谱

基于 PHASE / SIGNAL 的像素欧普标志实验。340 个上游基础 SVG，103 个常用编辑选集，5 套延续色系。当前为参照 `index (8).en.html` 中 PHASE / HOLD 程序化材质修正的 3.1 版；完整库还包含工具、平台与产品，并非 340 家企业。

## 使用

打开 `index.html`，同目录脚本必须保留；也可通过本地 HTTP 服务器查看。浏览器运行不依赖网络、字体 CDN 或 npm 安装。

- 上方查看原始 SVG 与动态像素版，切换色系、黑白底色和目标显示尺寸。默认 128 格轮廓；32/48/64 格作为旧版对照。
- 暂停或拖动相位后，导出当前透明 SVG。宽高与目标显示尺寸一致，导出包含当前色系、轮廓、相位与底色对应的配色，不包含背景、检查网格或界面。
- 下方按常用品牌、企业、模型与产品或完整图标库筛选。搜索在当前筛选范围内进行。
- 整套 ZIP 包含原始 SVG，以及当前 40/96/240/768px × 五色系共 6800 个静态 SVG。旧版 1700 个 SVG 仍保留在 `exports/<色系>/` 作历史对照，不属于当前套装。批量版本均为 0 秒透明素材。
- 当前统一使用 128×128 轮廓遮罩。材质固定在标志内部的逻辑网格，缩放不会重新划分色带；黑白干涉随目标尺寸渐显。40–60px 尺寸上的细线仍需按实际用途与原图核对。

## 像素化的实质变化

轮廓与孔洞由二值方格重建，SVG 导出由整数坐标硬边方块组成；原始宽高比保留。参考 HTML 中字形充当遮罩、材质在内部连续流动的做法，使用统一的卷曲色带场、16 级蓝青紫红色序、局部条纹/棋盘黑白干涉和稀疏荧绿节点。不同品牌不再分别采用环向、径向或纵向公式。局部笔画厚度决定黑白干涉能否进入，以保留细线标志的识别性。黑场版本对材质整体反相，呼应参考 HTML 的反相转场。轮廓不扭曲，颜色随连续相位变化；12 秒循环在数学上闭合。

图谱界面是选材工具，不是节目包装画面；多标志索引不代表成片可以同时展示等权主体。原始比例与孔洞优先于主系统的细长字形偏好，不对企业标志做横向压缩。

## 来源与复现

上游：https://github.com/lobehub/lobe-icons

固定提交：`2e76c48721e91b9aaa40803a0fa2eb8aca7399c4`。采集该提交 `packages/static-svg/icons` 的基础 SVG，排除 color/text/brand/combine/avatar 变体；文件级 Git blob SHA 见 `manifest.json`。源文件原样保存在 `originals/`，未改写。

`pull.mjs` 拉取固定提交并用 Sharp 从 alpha 通道重建 32/48/64/128 格遮罩。`pixel-engine.js` 同时用于画布与 SVG 导出。`export.cjs` 生成历史 48 格资产，`export-scale.cjs` 生成当前四档资产；`scale-qa.cjs` 只生成 PNG 图谱、缩放帧和差异图。以前的透明 WEBM 属于 2.0 历史素材，本轮未做视频渲染。构建用 Node.js 与 Sharp；浏览器预览无需安装依赖。

`system-tokens.json` 是原动效图谱的色系快照。新增风格不修改旧图谱。

## 尺寸与静态验证

`scale-qa/atlas-small-white.png`、`atlas-small-black.png`、`atlas-large-white.png`、`atlas-large-black.png` 是 OpenAI、Claude、Midjourney、Mistral AI 的原尺寸图谱。`scale-qa/zoom-openai/` 与 `zoom-claude/` 各有 121 张独立 PNG，覆盖 40→768px、2 秒、60 fps 的缩放路径；联系表、变化频率图、最剧烈相邻帧差异图和逐帧数值在 `scale-qa/`。这些都是图片，不含视频编码。
